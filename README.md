# Minji Ski

Play: https://minjidaddy.github.io/minjiski/

Ranking: https://minjidaddy.github.io/minjiski/ski-ranking.html

Mobile portrait pixel skiing time attack: 10,000 m, three characters, carving snow, jumps, boosters, obstacles and a 400 m minimap. Touch and drag left/right to steer; release to go straight. Desktop: arrow keys. Choose EASY (100/125 km/h), NORMAL (130/165 km/h, default), or HARD (160/200 km/h, original settings); values are normal/boost speed limits. Lower difficulties reduce starting speed, sustained acceleration and boost pickup acceleration. Shared Supabase TOP 100 saves only the highest score per name.
