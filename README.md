# Minji Ski

Play: https://minjidaddy.github.io/minjiski/

Ranking: https://minjidaddy.github.io/minjiski/ski-ranking.html

Mobile portrait pixel skiing time attack: 10,000 m, three characters, carving snow, jumps, boosters, obstacles and a 400 m minimap. Touch and drag left/right to steer; release to go straight. Desktop: arrow keys. Shared Supabase TOP 100 saves only the highest score per name.

This repository contains compiled runtime files only. Original development sources and source maps are not included. Game artwork and audio are supplied for this game; inclusion does not grant standalone redistribution rights. Phaser license: PHASER-LICENSE.md.
